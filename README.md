# Accessible Learning

An early pilot plugin for designing and reviewing adult-facing learning materials through the lenses of accessibility, Universal Design for Learning, inclusive design, and adult-learning quality.

## What it supports

- PowerPoint and Google Slides decks
- Documents, PDFs, and facilitator guides
- E-learning modules, workshops, and course outlines
- Design guidance from the start or prioritized review feedback

The plugin provides practical guidance; it does not issue legal or technical accessibility certification.

## Try it

Install the plugin from a Codex-compatible marketplace, then ask:

> Use Accessible Learning to review this slide deck for accessibility, UDL, and adult-learning design. Prioritize the five most important improvements.

## Pilot feedback

Please share what you reviewed, what feedback was useful or missing, and any recommendation that felt impractical in your setting. Do not include confidential learner or organizational information.

## Foundations

- WCAG 2.2 for practical digital-accessibility guidance
- CAST UDL Guidelines 3.0
- Adult-learning, inclusive-design, and cognitive-load principles
